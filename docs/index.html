Que es este proyecto

Skills pequenos, claros y accionables.

Este repositorio reune instrucciones especializadas para que un asistente de programacion aplique criterios consistentes en tareas concretas. La idea no es llenar el contexto con teoria, sino activar una guia practica cuando el trabajo lo necesita.

Cada skill define cuando debe usarse, que decisiones debe priorizar, que referencias puede consultar y como debe responder. Eso ayuda a conseguir resultados mas predecibles y faciles de revisar.

Para que sirve

Mejor criterio para tareas de software.

Arquitectura

Separar reglas de negocio, casos de uso, adaptadores e infraestructura sin ceremonias innecesarias.

Diagramas

Crear y auditar diagramas como modelos de ingenieria, no como decoracion visual.

Revision

Encontrar riesgos reales, dependencias incorrectas, ambiguedades y oportunidades de mejora incremental.

clean-architecture

Version 1.0.0

Ayuda a disenar, implementar, revisar y refactorizar sistemas usando principios de Clean Architecture. Enfocado en fronteras, direccion de dependencias, casos de uso, puertos, adaptadores y testabilidad.
