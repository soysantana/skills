# Skills

A collection of skills for AI programming assistants, based on software engineering principles and best practices.

## Installation

Install skills interactively:

```bash
npx skills add soysantana/skills
```

Install a specific skill:

```bash
npx skills add soysantana/skills --skill clean-architecture
```

## Available Skills

### clean-architecture

**Version:** `1.0.0`
**Based on:** *Clean Architecture: A Craftsman's Guide to Software Structure and Design*  
**Author:** Robert C. Martin (Uncle Bob)

Helps design, implement, refactor, and review software systems using Clean Architecture principles.
